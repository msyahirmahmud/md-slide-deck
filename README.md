> Markdown to HTML Presentation Deck Converter allowing developers to turn standard `.md` files into sleek HTML presentation slides.

---

## 🌟 Features

- **⚡ Instant Markdown Parser**: Converts `---` rules into distinct presentation slides.
- **🎨 HTML5 Presentation Player**: Keyboard and click slide navigation.
- **🧪 Unit Tested**: Comprehensive slide parsing test coverage.

---

## 🚀 Quick Start

```bash
git clone https://github.com/msyahirmahmud/md-slide-deck.git
cd md-slide-deck
npm start
```

Run test suite:
```bash
npm test
```
